# Test Resources

This directory contains test data, benchmark scripts, and reference implementations for validation.

## ENT Reference Implementation

To benchmark against the original ENT implementation by John Walker:

1. **Download ENT** from Fourmilab:
   ```
   https://www.fourmilab.ch/random/
   ```

2. **Extract** the archive to `tests/ent_fourmilab_random/`

3. **Build** the reference implementation:
   ```bash
   cd tests/ent_fourmilab_random
   gcc -o ent ent.c iso8859.c randtest.c chisq.c -lm
   ```

4. **Run benchmarks** using the Python scripts:
   ```bash
   cd tests/scripts
   python entropy_benchmark_ent.py
   ```

## Test Files

Place random data files in `tests/testfiles/` for validation testing.

## Benchmark Results

- `benchmark_results.csv` - Performance comparison data
- `benchmark_report.html` - Visual benchmark report

These files are generated by the benchmark scripts and should not be committed.

## Test Suites

| Test Suite | Primary Target | Strengths / Capabilities | Input Types | Source / Distribution |
| --- | --- | --- | --- | --- |
| **DIEHARD** | PRNG sanity testing | 15 classical statistical tests (Birthday spacings, Parking lot, Craps, etc.). Historically foundational. | 32-bit binary files | [Community C Port (GitHub)](https://www.google.com/search?q=https://github.com/dparadise28/George-Marsaglia-s-Diehard-tests-c-) |
| **Dieharder** | PRNG / Stream verification | Extends DIEHARD with modern statistical tests, CLI piping, and automated p-value aggregation. | `stdin` stream, raw files, C API | [Duke Physics](https://webhome.phy.duke.edu/~rgb/General/dieharder.php) / [GitHub `rurban/dieharder](https://www.google.com/search?q=https://github.com/rurban/dieharder)` |
| **NIST SP 800-22 Rev 1a** | Cryptographic PRNG / TRNG post-processing | 15 statistical tests (Frequency, Runs, DFT, Complexity, Approximate Entropy) focusing on binary sequences. | Raw binary / ASCII text bitstreams | [NIST CSRC Official](https://csrc.nist.gov/projects/random-bit-generation/documentation-and-software) / [GitHub `terrillmoore/NIST-Statistical-Test-Suite](https://github.com/terrillmoore/NIST-Statistical-Test-Suite)` |
| **TestU01** | Algorithmic PRNGs | Academic benchmark batteries (**SmallCrush**, **Crush**, **BigCrush**). Far more stringent than DIEHARD/NIST. | C function pointers, custom generator APIs | [DIRO Univ. Montréal](https://www.google.com/search?q=http://simul.iro.umontreal.ca/testu01/tu01.html) / [GitHub `umontreal-simul/TestU01-2009](https://github.com/umontreal-simul/TestU01-2009)` |
| **PractRand** | High-throughput PRNGs & stream ciphers | Tests data dynamically up to **32+ Terabytes** of output; ultra-sensitive to low-weight linear flaws. | `stdin` binary stream, C++ API | [SourceForge PractRand](https://pracrand.sourceforge.net/) / [GitHub `MartyMacGyver/PractRand](https://github.com/MartyMacGyver/PractRand)` |
| **NIST SP 800-90B** | Raw physical noise (TRNG/QRNG) | Min-entropy estimation on unconditioned noise sources (IID and non-IID tracks) prior to extractors. | Raw binary/byte files | [GitHub `usnistgov/SP800-90B_EntropyAssessment](https://github.com/usnistgov/SP800-90B_EntropyAssessment)` |
| **AIS 20 / AIS 31** | Physical TRNG certification | German BSI standard for hardware random sources; includes online health testing and stationary evaluation. | Raw digitized physical noise | [BSI Germany Portal](https://www.bsi.bund.de) |
| **ENT** | Quick sanity checks | Rapid measurement of Shannon entropy, Chi-square distribution, arithmetic mean, Monte Carlo $\pi$, and serial correlation. | Arbitrary binary/byte files | [Fourmilab ENT](https://www.fourmilab.ch/random/) |
| **gjrand** | Generator benchmarking | Lightweight C suite with multiple standardized test profiles for standard and long bitstream runs. | `stdin` stream, C library | [SourceForge gjrand](https://gjrand.sourceforge.net/) |
| **RaBiGeTe** | Multi-test aggregation | GUI-supported framework implementing DIEHARD, NIST, and custom statistical tests with parallel execution. | Binary files | [SourceForge RaBiGeTe](https://www.google.com/search?q=https://rabigete.sourceforge.net/) |
