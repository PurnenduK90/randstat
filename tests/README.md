# Test Resources

This directory contains test data, benchmark scripts, and reference implementations for validation.

## ENT Reference Implementation

To benchmark against the original ENT implementation by John Walker:

1. **Download ENT** from Fourmilab:
   ```
   https://www.fourmilab.ch/random/
   ```

2. **Extract** the archive to `tests/ent_fourmilab_random/`

3. **Build** the reference implementation:
   ```bash
   cd tests/ent_fourmilab_random
   gcc -o ent ent.c iso8859.c randtest.c chisq.c -lm
   ```

4. **Run benchmarks** using the Python scripts:
   ```bash
   cd tests/scripts
   python entropy_benchmark_ent.py
   ```

## Test Files

Place random data files in `tests/testfiles/` for validation testing.

## Benchmark Results

- `benchmark_results.csv` - Performance comparison data
- `benchmark_report.html` - Visual benchmark report

These files are generated by the benchmark scripts and should not be committed.
